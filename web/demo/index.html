Acme Checkout (sample host app)

This page hosts the embedded Pinpost Web SDK. The floating button in the corner is injected by the SDK; submissions go through POST /v1/feedback, and attachments are uploaded directly via a signed URL from POST /v1/attachment-uploads. Duplicate clicks are deduped by an idempotency key.

Pretend this is your product page — cart, checkout button and so on.
