# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repository. Do not open a public issue.

Include the affected component (server, admin console or an SDK), the version
or commit, and the steps to reproduce. We aim to acknowledge a report within
three working days.

Pinpost is built to keep tenants isolated and to treat uploaded files as
untrusted, so reports about cross-tenant access, authentication bypass, the
public write key reaching beyond ingestion, or attachments evading the malware
scan are especially welcome.
